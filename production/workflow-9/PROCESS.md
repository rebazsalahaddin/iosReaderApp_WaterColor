# Workflow 9: preserve accepted art, generate only the necessary change

This revision supersedes workflow 8's two-attempt cap, mandatory uploaded correction collage, verbatim retry-prompt rule and prohibition on safe shadow-matte repair. It does not approve any image, reset any attempt, authorize Chapter 2, or replace exact story/geometry requirements. The user's 8 November revision request authorizes these control changes. Existing raw returns, audits, deliveries and approvals remain historical facts.

## 1. Define the page and choose the least expensive route

Read the exact passage, measured current layouts, camera group and required unique beat. Inspect accepted sources before generation. Choose one route:

- `reuse`: an accepted complete state already meets the page. No paid job.
- `local_preparation`: placement, canonical drawing insertion, extraction or a verified matte-only correction. No paid job. Save a derivative and a fresh audit.
- `registered_edit`: a same-parent face or connected-action edit with a feasible local boundary. Generated pixels are candidates only inside the reviewed change mask.
- `whole_contact_candidate`: a new posture/contact/camera, or an edit whose boundary cannot safely be integrated. Preserve identity through reference and inspection; do not promise exact regenerated furniture or proportions.
- `identity`, `asset`, `background`: only genuinely missing necessary sources; audit/reuse first.

Do not call every hand/prop action an expression-only edit. Classify the change first. Do not create a new foundation or ID to refresh a failed state's budget. The catalog remains the canonical identity and attempt graph; a changed implementation route uses the same node ID and inherited count.

## 2. Keep separate authorities and contracts

The manuscript governs event, chronology and object meaning. Accepted character views govern identity, age, dot eyes, face, hair and wardrobe. Measured current layouts govern scale/camera/support anchors. A frozen scene master governs stationary furniture and existing light/shadow. Conflicting authorities must be resolved before submission. Never send a giant reference bundle to outsource this resolution.

Audit every existing identity before creating a new one. For a genuinely new neutral/contact master, use one clean suitable identity view plus only indispensable furniture/contact authority, with explicit input roles (maximum three). Inspect the entire generated group on its real background at intended scale before accepting it. Check two comparable anatomical measurements, internal actor ratios, rigid anchors, all contacts, crop margins and pixel budget. Record pose projection uncertainty; do not average incompatible measurements or stretch anatomy.

An expression/action sibling always starts from the same accepted clean neutral parent. It never starts from another expressive return. All first submissions and visual retries use that parent's original accepted bytes as the sole reference. Diagnostic boards remain local review evidence. Do not replace the clean source with a smaller opaque collage of successes and failures.

## 3. Plan the edit as an object-state transition

Fill `edit-plan-template.json`, with actual measurements and an actual reviewer. It is not ready while any required field is null. For every affected prop record stable object ID, before/after count, state and position, ownership, contact, and old/new native bounding boxes. Explicitly name what disappears and what surface must be revealed. Inventory unaffected objects too.

For Chapter 1 imagining: there is one blue book. The closed far-left instance must be replaced by that same book open near the hands; no closed copy may remain. The old footprint must reveal plausible table pigment. One separate blank sheet and one pencil remain. This is a connected action/prop edit, not merely a changed gaze. A mask that covers only the face or new book is invalid.

For `registered_edit`, make a binary native-canvas edit mask covering the union of old and new silhouettes, the entire changed contact (hand + held object + local support surface), vacated regions and any needed seam. Everything outside is protected. Keep stationary feet, table/chair supports and ground shadow outside the edit mask. A narrow facial edit may remain inside the face, but a head turn includes the old/new head silhouette and neck transition. Never paste a detached head, hand or limb from another pose.

Preplan at least three noncollinear unchanged landmarks near the boundary and a final-scale residual tolerance. A changed head is not a registration anchor. Default same-canvas integration uses no warp/rescale. Any one global similarity registration must be measured and reviewed in a separate derivative first; never automatic local warping. If rigid anchors disagree, the source is structurally incompatible. Stop or use the whole-contact route within the same canonical budget. Do not enlarge masks after the return merely to hide regressions.

## 4. Submit a concise, unambiguous target

Use the stage-specific Flare/Sunburst route above, medium / 2K / 4:3 / one PNG. Set transparent for isolated art and opaque for background plates. Verify actual live MCP schema and cost. The saved schema does not expose mask, markup, seed, temperature, input-fidelity or reasoning-effort fields. A local mask constrains our compositor, not the generator. Do not claim otherwise or send guessed API fields.

The node prompt carries the semantic brief. A measured `submission_contract` supplies necessary object transitions, direction and contacts without copying the whole audit. On a retry, keep the old submitted prompt immutable, write a new prompt version and explain the semantic diff. Cover every unresolved source issue; remove contradictory instructions. Do not require repeating a flawed original verbatim. Preserve passing features through the frozen edit plan and clean parent.

A correction board is mandatory offline evidence for material retries, with issue IDs, failed crops and intended fixes. It is never the sole uploaded art authority. Source failure crops are not new identity references. Upload only the exact clean accepted inputs for that stage. All prompt versions, masks, input hashes and return bytes stay traceable.

## 5. Integrate and audit locally

For a registered edit, use the accepted parent outside the mask and the same-parent candidate inside it. The included `registered_edit.py` performs replacement, not source-over blending: transparent pixels in the replacement can remove the old silhouette. It refuses dimension mismatch, nonbinary masks, whole-canvas edits, support-mask overlap or overwriting a file. A separate integration review must confirm registration, continuity at the boundary, identity, all changed contacts and object inventory. A diagnostic candidate is not an accepted source.

Exact pixel equality outside the mask is a technical invariant. It cannot certify the new face, correct table pigment inside the mask or a natural seam. Review at native resolution and intended reading size on the actual page. If the edit demands incompatible joints, a changed seat/footprint or a missing surface that cannot be reconstructed coherently, do not hide the failure by patchwork.

Keep the accepted generated shadow and stationary support pixels outside edits. No second shadow. A new stance requires a physically compatible contact group. For an existing shadow-only defect, a reversible alpha adjustment is now permitted **only** after a visually reviewed mask separates the existing shadow from shoes, pale clothing, furniture, paper and intentional optical content. Preserve shadow pigment/footprint; do not fabricate a new ellipse, move it independently, globally erase low-alpha pixels or inpaint anatomy. If it is painted floor rather than separable shadow, or the mask cannot protect contact edges, local repair is blocked. Evaluate on intended background first, then pale/dark diagnostics; no universal alpha ceiling certifies quality. Retain raw source, mask, transform and all protected-pixel comparisons. Add a new derivative audit, never revise the old failure.

## 6. Prove the family before branching

One representative node per neutral family is designated in the active chapter plan, using the catalog default when it is in that chapter closure. This prevents a family test outside the active chapter from becoming an unreachable dependency. For the child/table family it is the difficult imagining transition. Generate at most one live job at a time. Siblings wait until the family canary has an accepted derivative, an actual composed-page review, and matching parent hash in the ledger. A neutral PASS alone is insufficient. Choose a representative that exercises the real risk, not an easy smiling face that avoids the prop/contact problem.

Keep separate statuses: procedural readiness; technical completion; visual acceptance; user chapter approval. None implies the next. Every page still needs exact text/chronology, unique meaning, recipient/gaze, measured same-camera scale, stable anchors, complete contacts, matched painted borders, readable selected thoughts and exactly three owner-linked puffs.

## 7. Spend at most three times, not automatically three times

Maximum **three** counted attempts globally per canonical state, including old sheet jobs, failed jobs and unknown submissions. The normal goal is one usable return, with at most one ordinary evidence-based correction. After two failures the third is locked until a documented changed mechanism addresses the actual cause and a no-cost feasibility review passes. A rewritten adjective or identical collage is not a changed mechanism. Accepted art gets no cosmetic retry. A new model, parent, filename, chat, local derivative or node alias cannot reset counts.

Every submission requires a finite total chapter credit budget covering both ledgers, plus a numeric bounded spend window in agent-state covering named nodes. A per-job window alone is not a chapter spending cap. The recovery default ceiling is one quoted credit per window, not an account balance assertion. If a live quote exceeds the window, re-plan within existing authority; never silently raise it. Track actual debit where available, otherwise the quote. Missing/NaN/negative costs block. Unknown jobs block new submissions globally until reconciled. Reserve atomically under one writer before calling MCP, store the window ID, and reconcile receipts immediately. No new budget window may conceal an unresolved prior submission or cost.

Before attempt three record: all earlier issue IDs and results; root-cause evidence; changed method; why local repair/reuse alone is insufficient; feasible edit boundaries/contacts; projected cost; and reviewer/time. A second failed implementation of the same mechanism stops that route, even if a slot remains. Third failure is terminal for that canonical state. No model shopping or renaming to continue.
